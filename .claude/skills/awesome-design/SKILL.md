# Awesome Design (DESIGN.md library)

Each folder in `design-md/<brand>/` holds a `DESIGN.md`: that brand's colours, type, spacing, components and tone, written for an AI agent to follow.

## How to use

1. Pick 1–3 brands whose feel fits the project. List them with `ls design-md/`.
2. Read their `DESIGN.md` files. Borrow principles (spacing rhythm, type scale, restraint, component patterns); never copy logos, brand names or trademarked assets.
3. Write the chosen direction into the project's own `DESIGN.md` (or design tokens) so later work follows it.

## Good starting points for a local trades / service business site

- `airbnb`: warm, friendly, photo-led, trustworthy
- `apple`: restraint, big imagery, very clean
- `uber`: bold, high contrast, direct
- `wise` / `stripe`: clear pricing and calculators
- `notion`: calm, simple, text-first
